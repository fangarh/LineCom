# Технический стек

## Принятое решение

- Frontend: React.
- Backend: .NET.
- База данных: PostgreSQL.
- Frontend-приложение создано в `apps/front` как Next.js App Router + React + TypeScript проект.
- Backend-приложение создано в `apps/api` как ASP.NET Core Web API проект.
- .NET solution создан в корне: `LineCom.sln`.

## Контекст

Проект разрабатывается как интернет-магазин для компании по продаже кабеля.

Эта заметка фиксирует базовый стек. Детали по версиям, архитектуре, хостингу, авторизации, платежам, интеграциям и админ-панели пока не определены.

## SEO/GEO решение

Публичный frontend переведен на Next.js, потому что SEO/GEO является обязательным сквозным требованием. Для страниц каталога, категорий, товаров, брендов и регионов нужно использовать возможности App Router: статическую генерацию, server rendering, metadata, sitemap и canonical URL.

## Security note

В `apps/front/package.json` добавлен `overrides.postcss = 8.5.10`, потому что `create-next-app@latest` установил `next@16.2.4`, который транзитивно подтянул уязвимую версию `postcss@8.4.31`. После override `npm audit` показывает 0 уязвимостей.
