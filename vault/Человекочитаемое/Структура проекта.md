# Структура проекта

## Основные папки

- `apps` - приложения проекта: frontend, backend и другие сервисы.
- `temp` - обязательная папка для артефактов моего тестирования и вспомогательных систем.
- `Assets` - сопутствующие материалы: изображения, документы, прайсы, каталоги, референсы и другие исходные материалы.
- `vault` - Obsidian-хранилище и основная точка истины для контекста, решений и обсуждений.
- `vault/Человекочитаемое` - человекочитаемая часть контекста в Markdown.

## Правило

Новые приложения и сервисы размещаются внутри `apps`, если отдельно не согласовано другое место.

Ожидаемая структура:

```text
apps/
  front/
    src/
  api/
```

Текущее состояние:

- `apps/front` - Next.js App Router frontend на React + TypeScript.
- `apps/api` - ASP.NET Core Web API backend.
- `LineCom.sln` - solution для .NET backend.

Все артефакты моего тестирования, Playwright, Browser Use, скриншоты, временные отчеты, логи и файлы вспомогательных проверок размещаются только внутри `temp`. Это обязательное условие.
