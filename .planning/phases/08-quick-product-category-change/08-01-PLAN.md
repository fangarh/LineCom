<objective>
Add the first vertical slice for quick product category reassignment: a row-level category-change action, a focused modal, leaf-only category selection, and a save path that preserves all existing product fields while changing only `categoryId`.

User story: As an admin working in the product list, I want to change one product's category without opening the full editor so small catalog cleanup tasks are faster and less disruptive.

Purpose: Cover CATUX-01 and CATUX-02, establish the CATUX-03 warning surface, and keep the implementation on existing admin catalog contracts.
Output: helper module, quick category modal, product list row action, manager-owned save flow and focused tests.
</objective>
