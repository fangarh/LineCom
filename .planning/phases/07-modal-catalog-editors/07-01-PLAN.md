<objective>
Move the existing product editor into a reusable accessible modal while preserving product list state, stale-request safety, save/delete behavior and existing product editor tabs.

User story: As an admin editing catalog products, I want product rows and `New product` to open a focused modal editor so the product list keeps its working width and I can return to the same list context after closing.

Purpose: Cover AUX-01 and the product-list half of AUX-03/VER-01 without adding Phase 8 quick category changes.
Output: Shared modal shell, product modal wrapper, product manager modal session behavior and focused product manager tests.
</objective>
